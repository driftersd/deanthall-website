# Deployment

This site is a Vite-built React application with an Express production server. It is intentionally **not configured for Azure Static Web Apps**.

## Verification

Run the following commands from the repository root before publishing:

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm build
PORT=3000 NODE_ENV=production pnpm start
```

The production server serves the `dist/` directory generated by `pnpm build`. A successful smoke test returns HTTP 200 for both `/` and any browser route, such as `/research`.

## Managed hosting

Use the Manus managed web-hosting workflow for this project. Configure the service to run `pnpm build` during build and `pnpm start` at runtime. The host must provide the `PORT` environment variable; do not set a fixed port in deployment settings.

After the site is published, connect `deanthall.com` and `www.deanthall.com` through the hosting project’s domain settings. Remove the obsolete DNS or platform mapping that currently routes the domain to a maintenance page before adding the new records.

## Deployment scope

The site has no application-specific secret requirements. It reads optional Manus title, logo, and OAuth configuration in its browser code, but the public website itself does not require a database, email provider, or third-party API key to render.
